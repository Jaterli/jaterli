Migración completa de 9 aplicaciones interactivas independientes desde JavaScript puro hacia el ecosistema de React[cite: 10]. ### ⚙️ Automatización de Gráficas con GitHub Actions

<a href="https://jaterli.com/proyectos/entry/2024/github-action-automatizar-flujos-de-trabajo/">
  <img src="https://jaterli.com/images/proyectos/projects.github-actions.jpg" alt="Automatización GitHub" width="600" style="border-radius: 8px; box-shadow: 0 4px 8px rgba(0,0,0,0.1);">
</a>

![GitHub Actions](https://img.shields.io/badge/GitHub_Actions-2088FF?style=flat&logo=github-actions&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)
![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat&logo=streamlit&logoColor=white)

Sistema CI/CD completamente automatizado que aprovecha la infraestructura de GitHub Actions para extraer y visualizar métricas de actividad de mi blog sin intervención manual[cite: 2]. Emplea un script en Node.js que procesa los metadatos de archivos Markdown para alimentar una base de datos JSON[cite: 2]. Posteriormente, un flujo en Python (usando Matplotlib y Streamlit) lee estos datos, genera una gráfica de barras actualizada mensualmente, y realiza un commit automático para reflejar los cambios en el frontend de la web[cite: 2].
